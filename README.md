# TejoGestion

Sistema web para la gestión de procesos administrativos y operativos del establecimiento Clan Elite 2.

## Módulo 01: Reservas de Canchas

Este módulo busca facilitar la administración de las reservas de las canchas de tejo.

## Tecnologías propuestas

- Java
- MySQL
- HTML
- CSS

## Base de datos

El archivo tejogestion.sql contiene las instrucciones para crear la base de datos y sus tablas:

- Cliente
- Cancha
- Reserva
